# CUR (Crucsi Universal Repository)

المستودع الرسمي لحزم ونظام تشغيل **Crucsi**.

## الحزم المتاحة:
- **python3**: لغة البرمجة بايثون الإصدار 3.14.
- **nim**: لغة البرمجة Nim الإصدار 2.0.

## كيفية الاستخدام داخل Crucsi:
```sh
cpm install python3
cpm install nim
cpm search <pkg>
cpm remove <pkg>
